# Sign in (Next.js)

```bash
npm install
npm run dev
```

Then open http://localhost:3000. The page is `components/LoginPage.jsx` (a client component, it uses state), shown by `app/page.jsx`.

Change `--brand` and `--brand-2` at the top of the page's CSS to match your brand. The logo (also the favicon) is in
`public/`.
