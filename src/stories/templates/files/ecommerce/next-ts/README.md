# E-commerce store (Next.js + TypeScript)

A ready-to-run Next.js App Router project.

```bash
npm install
npm run dev
```

Then open http://localhost:3000. The page is `components/ShopPage.tsx` (a client component, it uses state),
shown by `app/page.tsx`; `npm run build` makes a production build.

Change `--brand` and `--brand-2` at the top of the page's CSS to match your brand.
