# E-commerce store (Vue)

A ready-to-run Vue + Vite project: a full store page with search, category filters, sorting, product cards
and a cart drawer.

```bash
npm install
npm run dev
```

- The page is `src/ShopPage.vue`, its styles `src/shop.css`.
- Products, categories and the cart math are in `src/shop-data.js`: replace `PRODUCTS` with your catalog
  and `checkout()` with your payment flow.
- Change `--brand` and `--brand-2` at the top of the CSS to match your brand.
