# E-commerce store (Angular)

A ready-to-run Angular 21 project (standalone components, signals, zoneless).

```bash
npm install
npm start
```

Then open http://localhost:4200. The page is in `src/app/shop-page/`; `npm run build` builds it into `dist/`.

To use the page in an app of your own, copy the `src/app/shop-page/` folder and add `ShopPageComponent` to a route or a template.
Change `--brand` and `--brand-2` at the top of its CSS to match your brand.
